# reflex-openbb documentation

Welcome to the reflex-openbb documentation. This directory contains
the project's **Spec-Driven Design (SDD)** artifacts, plus user-facing
guides.

## Spec-Driven Design

The project was designed using the [ecrespo Spec-Driven Design](./constitution.md)
methodology. The 9 artifacts live in [`../specs/`](../specs/):

| Artifact | Path | Description |
|----------|------|-------------|
| Constitution | [`../specs/constitution.md`](../specs/constitution.md) | 9 articles governing every decision |
| PRD | [`../specs/prd/mvp.md`](../specs/prd/mvp.md) | 10 user requirements (REQ-001..010) |
| Architecture | [`../specs/technical/v1-architecture.md`](../specs/technical/v1-architecture.md) | System design |
| Data model | [`../specs/data-model/v1-models.md`](../specs/data-model/v1-models.md) | Pydantic types |
| Tasks | [`../specs/tasks/v1-tasks.md`](../specs/tasks/v1-tasks.md) | Task breakdown by phase |
| API | [`../specs/api/v1.md`](../specs/api/v1.md) | Function signatures |
| Plan | [`../specs/plans/v1-phase-plan.md`](../specs/plans/v1-phase-plan.md) | Execution plan |
| Analyze | [`../specs/analyze-v1.md`](../specs/analyze-v1.md) | Traceability matrix |
| Changelogs | [`../specs/changelog/`](../specs/changelog/) | Phase completion changelogs |
