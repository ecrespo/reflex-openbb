# API Spec — reflex-openbb v1.0

> Status: `DRAFT` · Date: 2026-08-08 · Owner: Ernesto Crespo
> Implements: REQ-001..010 from `prd/mvp.md`

This API is the **internal Python interface** between the Reflex state layer and the data layer. It is NOT a network API (the app is local-only; Art. 7). All functions are async and return Pydantic models.

## Endpoints (Python module functions)

### `data.equity`

#### `get_equity_quote(ticker: str) -> EquityQuote`
- **REQ:** REQ-005 (KPI cards)
- **Input:** `ticker` (str, uppercase, validated against regex `^[A-Z][A-Z0-9.\-]{0,9}$`)
- **Output:** `EquityQuote` (Pydantic, see Data Model)
- **Errors:**
  - `InvalidTickerError` if regex fails
  - `ProviderError` if OpenBB SDK returns non-200
- **Cache:** 5 min TTL, key = `quote:{ticker}`

#### `get_equity_price_history(ticker: str, period: Literal["1mo","6mo","1y","5y","max"]) -> list[OHLCBar]`
- **REQ:** REQ-001, REQ-002
- **Input:** `ticker`, `period` (default `"1y"`)
- **Output:** list of `OHLCBar`, sorted ascending by `date`
- **Downsampling:** if > 5000 bars, the implementation downsamples to ~2000 visible points using LTTB (Largest Triangle Three Buckets) before returning
- **Errors:** `InvalidTickerError`, `ProviderError`
- **Cache:** 5 min TTL for "1mo"/"6mo"/"1y"; 1 day for "5y"/"max"

#### `get_equity_fundamentals(ticker: str) -> EquityFundamentals`
- **REQ:** REQ-003
- **Input:** `ticker`
- **Output:** `EquityFundamentals` (Pydantic)
- **Errors:** as above
- **Cache:** 1 day TTL

#### `get_equity_news(ticker: str, limit: int = 10) -> list[NewsItem]`
- **REQ:** REQ-004
- **Input:** `ticker`, `limit` (1..50, default 10)
- **Output:** list of `NewsItem`, sorted descending by `published_at`
- **Errors:** as above
- **Cache:** 15 min TTL

### `data.crypto`

#### `get_crypto_price_history(symbol: str, period: Literal["1mo","6mo","1y","5y","max"] = "1y") -> list[OHLCBar]`
- **REQ:** REQ-006
- Same shape as the equity version; symbol examples: `BTC`, `ETH`, `BTC-USD`

### `data.economy`

#### `get_economy_indicator(indicator: Literal["GDP","CPI","UNRATE"], country: str = "US") -> list[MacroPoint]`
- **REQ:** REQ-007
- **Input:** indicator, country (ISO-3166 alpha-2)
- **Output:** list of `MacroPoint` (year + value)
- **Cache:** 7 days TTL (macro data is updated slowly)

### `data.search`

#### `search(query: str) -> SearchResult`
- **REQ:** REQ-010
- **Input:** `query` (1..20 chars)
- **Output:** `SearchResult` with `equity_match: str | None`, `crypto_match: str | None`, `confidence: float`
- **Errors:** none (always returns a result, even if no match)
- **Cache:** none (cheap)

## Endpoints (Reflex event handlers exposed to the UI)

These are state class methods that the UI binds to. They call into the `data` module and update state.

### `EquityState` (on `/equity/{ticker}`)

| Event handler | Args | Effect |
|---|---|---|
| `set_ticker(ticker: str)` | `ticker` | Validates and stores; triggers `load_quote`, `load_price`, `load_fundamentals`, `load_news` |
| `set_period(period: str)` | `period` | Stores; triggers `load_price` |
| `add_to_comparison(ticker: str)` | `ticker` | Validates (≤ 5 tickers), fetches price, appends to `comparison_tickers` |
| `remove_from_comparison(ticker: str)` | `ticker` | Removes from `comparison_tickers` |
| `export_csv()` | none | Triggers a CSV download of the current chart data |

### `CryptoState` (on `/crypto/{symbol}`)

| Event handler | Args | Effect |
|---|---|---|
| `set_symbol(symbol: str)` | `symbol` | Validates and stores; triggers `load_price` |

### `EconomyState` (on `/economy`)

| Event handler | Args | Effect |
|---|---|---|
| `set_indicator(indicator: str)` | `indicator` | Stores; triggers `load_indicator` |
| `set_country(country: str)` | `country` | Stores; triggers `load_indicator` |

### `AppState` (global)

| Event handler | Args | Effect |
|---|---|---|
| `global_search(query: str)` | `query` | Calls `data.search.search()`; navigates to the appropriate page or shows "not found" |

## Rate limiting

The `data` module is the only place that calls the OpenBB SDK. It enforces:
- A token-bucket rate limiter (default 5 requests / second) before calling the SDK
- A circuit breaker (open after 3 consecutive errors, retry after 60s) per provider

## Error model

All `data` functions may raise:
- `InvalidTickerError` (value error)
- `ProviderError` (network or rate limit; carries `provider`, `status_code`, `retry_after`)
- `CacheError` (only on cache write failure; non-fatal)

Event handlers catch these and surface a banner in the UI (not an exception).
